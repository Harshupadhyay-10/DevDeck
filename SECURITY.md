# Security policy

Dev Deck can run commands on a developer's computer, so security reports are
taken seriously.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

A private reporting channel will be added here before the first public
release. Until then the project is not published and has no supported
versions.

## What the project collects

Nothing. There are no accounts, no analytics, no crash reporting and no
servers operated by the project. Communication happens only between your own
devices on your local network.

## Design reference

The threat model and the rules the code must follow are in
[docs/THREAT_MODEL.md](docs/THREAT_MODEL.md). A change that conflicts with
those rules needs the threat model updated first, with the reasoning.
